# proto-tools

Collection of [proto](https://moonrepo.dev/proto) TOML plugins.

## Usage

Reference a plugin from your `.prototools`:

```toml
[plugins]
hl = "https://raw.githubusercontent.com/splitsec-labs/proto-tools/main/toml-plugins/hl/plugin.toml"
```
